# cnctd_mta

NYC MTA subway information library for Rust.

## Installation

```toml
[dependencies]
cnctd_mta = { git = "https://github.com/Connected-Dot/cnctd_crates.git" }
```

## Features

- Train arrival times
- Service alerts
- Station information
